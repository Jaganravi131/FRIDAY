## Architecture assessment

FRIDAY is a local-first Python assistant, not a bundled language model. Its core
runs on the standard library and SQLite. Human-editable Markdown is the source
of truth; the database, full-text index and vector index are derived artifacts.
The agent combines retrieval, an attention-budget ledger, deterministic tool
permissions, audit logging, connectors and a token-authenticated HTTP gateway.
A mock client exercises these paths without model weights. Recurrent-state
operators and training scripts are research components, not evidence of a trained
production model.

The existing suite covers many safety and memory invariants. The main gaps found
in this pass were outside those tests: built-package installation, malformed
HTTP inputs, and a mock-client failure after tool observations.

## Still open / not claimed solved

1. **Independent retrieval holdout (T-002):** needed before choosing between the
   synonym and concept implementations or claiming general paraphrase quality.
   The committed paraphrase score is based on only four queries.
2. **Real-model validation (T-003, T-007):** requires weights and the user's hardware.
   Mock success measures plumbing, not model intelligence.
3. **Research specification (T-010):** `erase_rank_one=False` duplicates the true
   operator branch. The existing expected failure remains until the intended math
   is specified; this pass did not invent a research definition.
4. **Hardware/network checks:** idle model unloading and actual phone connectivity
   still require manual verification. The gateway's server-side check passed.
5. **Known security limitations:** DNS rebinding, rate limiting, and runtime
   sandboxing remain as documented in `SECURITY.md`; this was not a complete
   security audit.
6. **Installed-package usage:** explicitly set `FRIDAY_ROOT` to a separate data
   directory. The default path has not been redesigned. For a wheel installation,
   supply `bench --gate --file <path-to-BENCHMARKS.md>`; the repository baseline
   is not bundled into the wheel.

All work is on the session branch. This review does not merge changes into `main`,
publish a package, or claim that remote CI has run for these fixes.
